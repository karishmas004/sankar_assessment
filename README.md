# Daybook – SaaS Landing Page

Landing page for **Daybook**, a fictional async-standup tool. Built for the Sankar Group front-end internship assignment.

## Technologies
HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript. No build step, no dependencies, no backend.

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
npx serve .
```
Deploy: drag the folder to Netlify Drop, or enable GitHub Pages on the repo.

## Features
- Sticky navbar, smooth-scroll links, mobile menu (Escape closes it)
- Hero, features, how it works, pricing (monthly/yearly toggle), demo form, footer
- Pricing buttons pre-select the plan in the form
- Form validation with inline errors, loading state, and success message
- Accessible labels, ARIA attributes, visible focus, reduced-motion support

## Files
`index.html` (structure) · `styles.css` (design tokens + responsive layout) · `script.js` (interactions)
